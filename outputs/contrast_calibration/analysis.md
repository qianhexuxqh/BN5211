# BN5211 Phase 4：Log-Affine Calibration 简要结果

## 固定方法与数据边界

采用标准的全局对数空间线性最小二乘校准，不声称算法新颖。仅使用trans_t1_a的61帧缓存原始预测和GT，在c3vd-interior-v1掩码（0 < depth_raw < 65535）的全部80,952,223个有效像素上拟合：

log(GT_mm) = a + b * log(original_prediction_mm)

自然对数、毫米单位、每像素等权。float64中心矩按帧合并：b=Sxy/Sxx，a=mean_y-b*mean_x；没有逐帧参数、模型训练或超参数搜索。固定结果：

- a = -26.367917618101938
- b = 4.791517002825514
- corrected_mm = exp(a + b * ln(original_prediction_mm))

参数在测试评价前冻结。使用全部103帧既有测试预测，未重新调用深度模型，未利用测试GT调整参数。既有outputs/results/与outputs/calibration/保持不变。

b>1扩大了预测的对数深度对比度；P05–P95宽度由约6.39 mm增加到35.03 mm，但仍小于GT约54.12 mm。中位数略高于GT，远端P95仍偏低，不能声称完全恢复真实深度分布。

分位数是所有有效像素的精确线性经验分位数。使用新建临时磁盘映射池计算相邻次序统计量，先分别变换，再插值；未把非线性变换后的原始分位数当作精确结果。临时池已移除，不修改原预测。

103帧、136,655,314个共同有效像素，全像素汇总。相对Global Scale，Log-Affine的AbsRel降低10.5384%，RMSE降低21.3895%（3.57006244 mm），δ下降1.95829853个百分点。开发集三项改善，但测试集并非全部指标改善；Global Scale保留更高的测试δ。

原始模型全局中位数约为GT的26.168倍，Global Scale主要修正整体尺度，Log-Affine进一步扩张变化幅度。对数平方误差最优不保证δ阈值内像素比例最优；本次指标取舍需明确报告，不选择性隐藏δ下降。两种校准均为开发集监督的后处理，原始模型结果才是不校准零样本性能。

## 主要剩余误差

分布仍偏窄，不能据此认定精确几何恢复。变换还产生长尾：开发集3,621个有效像素预测超过100 mm，最大2055.51 mm；测试集6,565个有效像素超过100 mm（约0.004804%），最大1935.61 mm。这些是有限正值的实际方法输出，全部保留并计入指标；没有裁剪或删除差像素。本轮未进一步调参，也未对长尾来源作未经验证的归因。

## 可视化、验证与停止点

固定测试帧0000、0051、0102，展示RGB、GT、Global Scale、Log-Affine及两种绝对误差。GT与两种预测统一0–100 mm，两种误差统一0–100 mm；超过显示上限的像素数量和色条箭头均有标注，显示饱和不等于数值裁剪。三张图已查看。

5项新方法针对性检查均通过；新增实验产物核对冻结参数、直接残差SSE、183行开发及412行测试结果的全像素汇总，以及两个数据集首/中/末帧直接公式，均通过。没有重复旧全量完整性审计，没有发生数值异常或运行错误。

本轮唯一指定方法已完成并停止，未追加其他算法或优化。
