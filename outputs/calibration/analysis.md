# BN5211 Phase 3 简要分析

本轮仅采用预先指定的开发集全局中位数比例校准，没有更换模型、训练、微调、裁剪预测或尝试其他校准公式。

## 尺度偏差与固定系数

61帧开发集、80,952,223个有效像素：GT全局中位数为17.25947966735332 mm，预测全局中位数为451.6485900878906 mm，后者是前者的26.168146363195042倍。

唯一固定系数为0.03821439952684151，即GT中位数/预测中位数。GT从无损uint16直方图按float64解码统计，预测由全部有效float32像素精确池化计算，均不是帧中位数的中位数。系数在校准测试评价之前冻结。所有测试帧共用同一系数；测试GT不参与拟合或调参。

## 结构诊断及局限

开发集固定有效像素上的逐帧Pearson：61帧均为正；均值0.7837313918803526，中位数0.7865349239751157，范围0.6200953814358919–0.8958611083546245。本轮没有零方差帧。程序对GT或预测零方差时记录null和原因，并单独计数，不把未定义相关性记为0。

结果支持预测包含部分图像内相对远近变化；Pearson只描述关联，不证明学习机制，不替代正式深度指标，也不是独立像素的显著性检验。

全局尺度偏差明显，但单一乘法没有恢复真实深度变化幅度。开发集GT的P05–P95为6.21194781–60.33417258 mm，校准预测约14.07882014–20.46521740 mm；校准后分布仍明显偏窄。因此不能把本轮结果描述为“尺度问题已解决全部深度误差”或“已恢复精确几何”。

## 可视化与保留

固定测试帧0000、0051、0102，独立于误差选择，展示RGB、GT、原始预测、校准预测和校准绝对误差。GT与校准预测统一0–100 mm；原始预测明确单独标注0–1300 mm；误差统一0–100 mm。掩码外灰色显示，不逐图归一化，不通过显示处理修改数值或指标。

只对61帧开发集进行了新推理。测试阶段复用已有103帧原始预测，未重新推理或再拟合。原始结果和原始预测指纹核对通过，校准系数、中位数及指标汇总复核通过。全部新产物保存在outputs/calibration/，本轮实验到此停止。
